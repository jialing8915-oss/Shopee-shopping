# Shopee shopping Assistant 
## About the program

This program is a simple c++ shopping assistant for Shopee.

The shopping assistant asks the user to choose a category and their budget. After doing so the assistant suggests an item based on the user's chosen product category and budget. 

## Features

- Pick a product category 
- Enter budget
- Get a product recommendation 
- choose quantity
- Use a voucher
- Choose a delivery method
- Calculate final price
- Check if final price is within given budget

  ## Categories

  - Clothing
  - Shoes
  - Furniture
  - Electronics
  - Leisure
  - Food
    
  ## How to Use

  1. Run the program.
  2. Choose a category from the menu.
  3. Enter desired budget.
  4. shopping assistant program will suggest a suitable product based on user's chosen category and budget.
  5. Enter desired quantity.
  6. Choose whether you have a voucher or not.
  7. Select a delivery method.
  8. Shopping assistant program will then calculate and show:
  - Product price
  - Quantity
  - Subtotal
  - Voucher discount
  - Delivery fee
  - Final price
  - Whether the final price is within user's budget
